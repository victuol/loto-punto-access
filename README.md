# Loto Punto Access

Genera un landing page en idioma inglés que servirá para testear una interfaz creada en FIGMA. Esta interfaz la embeberé posteriormente, simplemente crea un contenedor  para dicha interfaz y que pueda ser embebida con posterioridad a la creación del landing page.

Este landing page será informativo y con fines de marketing. A continuación te diré la idea de este sitio:

Description: In the United States, rising real estate costs and overhead have driven traditional bank branches out of low-income neighborhoods, creating vast "banking deserts". This structural decline leaves low-income adults facing severe financial strain, forced to navigate exorbitant transaction fees from out-of-network ATMs simply to access their own money.

Deprived of affordable institutional banking, vulnerable populations are increasingly pushed toward predatory alternatives—such as check cashers, payday lenders, and loan sharks—to meet basic liquidity needs. Because cash remains an unavoidable daily utility for 83% of Americans, bridging this physical gap with low-barrier, affordable access to cash is a critical economic necessity.

To address this inequality, Loto Punto is developing a cardless ATM interface that minimize transaction fees by leveraging dynamic QR codes and integration with existing mobile banking applications. However, driving adoption introduces a significant behavioral barrier: entrenched user habits around physical payment cards create cognitive friction when users transition to a completely new interaction model.

This behavioral friction underscores the core objective of this research: establishing a theoretical and practical framework for designing self-service financial interfaces that maximize economic accessibility while advancing resource conservation across human, computational, physical, and financial dimensions.
